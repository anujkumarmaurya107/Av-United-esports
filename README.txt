Free publishing option:
1. Create/sign in to a GitHub account.
2. Create a new public repository named av-united-esports.
3. Upload index.html and av-united-logo.png to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. After publishing, GitHub will show your free website address.
